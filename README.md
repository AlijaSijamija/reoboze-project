XY Cartesian system with extruder and pressure compensation

An application in B&R Automation Studio that simulates an XY Cartesian system with an
extruder, inspired by the operation of a 3D printer.
Hardware configuration Sim uses an X20CP1586 as a placeholder target with POWERLINK for 
the simulated ACOPOS axes; the project runs in ARsim only.

Tools and environment:

B&R Automation Studio 4.12.10.39
Automation Runtime R4.93 ARsim
mapp Motion 5.29
mapp Control 5.24
mapp View 5.24
